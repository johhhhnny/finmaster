### 一、 真实核心主营盈利穿透模型（剔除股权投资扰动）

#### 1. 会计失真痛点（US GAAP ASC 321 / ASU 2016-01）
Alphabet 的净利润包含大量非经营性“其他收益与支出净额”（Other Income and Expense, Net, 简称 `OI&E`），其中**上市与非上市股权投资的未实现公允价值变动**（如早期风投组合、AI 战略投资标的估值波动）直接计入当期损益，极易导致账面净利润与 EPS 出现非现金性质的剧烈扭曲。

#### 2. 巴菲特视角穿透还原公式
为还原核心主营业务（Google Services + Google Cloud - Other Bets 经营亏损）的真实造血能力，需按以下十进制步骤剥离非经营噪音：

1. **计算营业利润率与税前核心经营利润**：
   $$\text{核心营业利润} = \text{GAAP Operating Income}$$
   *（注：需核查当期是否包含一次性裁员遣散费、办公物业减值或反垄断巨额罚金，若有，需单独列示并评估其属于“非经常性一次性”还是“常态化监管成本”。）*
2. **还原真实核心经营净利润（不含投资浮盈亏）**：
   $$\text{核心税前利润} = \text{Operating Income} + \text{净利息收入 (Interest Income - Interest Expense)}$$
   $$\text{核心净利润} = \text{核心税前利润} \times (1 - \text{核心实际税率 } T_{\text{eff}})$$
   *（或自下而上校验：$\text{GAAP 净利润} - \text{股权投资净损益} \times (1 - \text{适用税率})$）*
3. **核算核心经营每股收益（Core EPS）**：
   $$\text{Core EPS} = \frac{\text{核心净利润}}{\text{最新加权平均稀释股本 (Diluted Shares)}}$$

#### 3. 巴菲特式灵魂拷问：股权激励（SBC）处理原则
* **严禁将 SBC 加回盈利**：华尔街常使用剔除 SBC 的 Non-GAAP 盈利美化估值，但巴菲特视 SBC 为**真实且昂贵的现金等效薪酬支出**。因此，上述 `Operating Income` **必须保留对 SBC 的全额扣减**，同时需审计股票回购金额是否真正实现了总股本的净缩减，而非仅仅在“高价回购对冲员工稀释”。

### 二、 现金流与资本开支审计框架（CapEx 吞噬与 FCF 质量）

在 AI 基础设施（TPU、GPU 集群与数据中心）军备竞赛周期中，仅看利润表具有极强滞后性，必须审计现金流量表的资本吞噬强度：

1. **核心指标测算公式**：
   * **自由现金流（FCF）**：
     $$\text{FCF} = \text{经营活动现金流 (OCF)} - \text{资本开支 (CapEx, Purchases of property and equipment)}$$
   * **CapEx 吞噬比例**：
     $$\text{CapEx 吞噬率} = \frac{\text{CapEx}}{\text{OCF}} \times 100\% \quad ; \quad \text{资本密集度} = \frac{\text{CapEx}}{\text{营业收入}} \times 100\%$$
2. **真实质量二次审计（Owner Earnings 视角）**：
   * **扣减 SBC 后的真实自由现金流（True FCF）**：
     $$\text{True FCF} = \text{OCF} - \text{CapEx} - \text{SBC}$$
     *（审计标准：若回购金额仅勉强覆盖 SBC 产生的稀释，则公司可自由分配给老股东的真实回报应以 `True FCF` 为准。）*
   * **折旧滞后风险（Depreciation Lag）预警**：
     当前周期的巨额 CapEx 不会立即全额冲击利润表，而是会在未来 4–6 年内转化为持续上升的折旧摊销（D&A）。审计时需对比 $\frac{\text{当期 CapEx}}{\text{当期 D\&A}}$：若该比值显著大于 $1.5\times \sim 2.0\times$，意味着**未来数年的营业利润率将面临刚性折旧侵蚀压力**，除非 AI 云业务与搜索商业化能够释放超额增量毛利。

### 三、 资产负债表与净现金储备拆解模型

巴菲特对“堡垒式资产负债表”的审视要求**只计算高流动性可变现资产，严格剔除流动性受限资产**：

1. **纯流动性现金池（Pure Liquidity Pool）**：
   $$\text{总纯流动性现金} = \text{现金及现金等价物 (Cash \& Equivalents)} + \text{短期有价证券 (Marketable Securities)}$$
   * **剔除项**：**必须剔除**资产负债表中的非流动性长期股权投资（Non-marketable investments）及受限现金（Restricted cash），防止在安全边际测算中计入难以按账面价值变现的资产。
2. **刚性负债与隐性负债扣减**：
   $$\text{广义有息债务} = \text{短期借款} + \text{长期借款 (含一年内到期)} + \text{经营租赁负债 (Operating Lease Liabilities)}$$
   *（注：若进行极致保守测算，需将经营租赁负债视为类债务承诺一并扣减。）*
3. **每股纯现金测算公式**：
   $$\text{每股纯现金 (Net Cash / Share)} = \frac{\text{总纯流动性现金} - \text{广义有息债务}}{\text{最新期末稀释总股本}}$$

### 四、 估值与安全边际测算框架（核心 PE 与 Ex-Cash PE）

为消除账面巨额净现金对估值的视觉干扰，必须严格匹配分子与分母的口径：

1. **真实核心主营 PE（Core PE）**：
   $$\text{Core PE} = \frac{\text{最新收盘股价 } P}{\text{TTM 核心经营 EPS}}$$
2. **扣现金市盈率（Ex-Cash Core PE）——【口径一致性修正】**：
   在剥离分子中的“每股纯现金”时，**必须同步剥离分母中这部分净现金所产生的税后净利息收益**，否则会造成估值低估：
   $$\text{每股核心业务经营收益 (Ex-Interest Core EPS)} = \frac{(\text{TTM Operating Income}) \times (1 - T_{\text{eff}})}{\text{稀释总股本}}$$
   $$\text{Ex-Cash Core PE} = \frac{\text{最新收盘股价 } P - \text{每股纯现金}}{\text{Ex-Interest Core EPS}}$$
3. **安全边际历史锚定（待数据补齐后执行）**：
   * 需将测算出的 `Core PE` 与 `Ex-Cash Core PE` 置于 GOOGL 过去 5 年（20 个季度）的滚动市盈率区间中，定位所处历史分位数（如 25% 以下低估区 / 50% 中枢区 / 75% 以上高估区）。
   * 同步测算 **Owner Earnings Yield（所有者盈余收益率）**：$\frac{\text{True FCF}}{\text{最新企业价值 EV}}$，并与当前 10 年期美国国债无风险收益率对比，评估股票风险溢价（ERP）是否具备足够安全边际。
